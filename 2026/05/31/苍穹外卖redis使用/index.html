苍穹外卖 — Redis 缓存使用

一、需求分析

菜品或套餐在用餐时间段会被大量访问，为了减少磁盘 IO、提高用户访问速度，使用 Redis 缓存代替直接读取数据库。

二、查询时插入 Redis 缓存

将 MySQL 数据写入 Redis：在查询套餐的 UserDishController 中调用 RedisTemplate，实现缓存逻辑。

查询流程

  1. 查看缓存 — 检查 Redis 中是否已有数据
  2. 缓存命中 — 有数据则直接返回
  3. 缓存未命中 — 查询数据库，将数据写入 Redis 缓存，然后返回数据

注意： Redis 中存储的数据为 String 类型，在 Java 中返回的是 Object，获取后需要强转为 List。

三、Admin 端修改时清理 Redis 缓存

Redis 中的数据需要在 Admin 端进行菜品修改时同步更新。在 AdminDishController 中调用 RedisTemplate 清理缓存。

清理策略

操作 清理策略
新增菜品 清理新增菜品所属分类的缓存
修改菜品 直接清除所有缓存
删除菜品 直接清除所有缓存

四、总结

  • 查询端（User）：先查缓存 → 缓存有则返回 / 缓存无则查库并回填
  • 管理端（Admin）：写操作后主动清理对应缓存，保证数据一致性
