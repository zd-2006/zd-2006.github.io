fork函数

fork

  • fork：分叉。
  • 作用：用于创建另一个进程。
  • 返回值为 int 类型。
  • 返回值：
    • 子进程中返回 0。
    • 父进程中返回子进程的进程号。
  • 两个进程平行运行，互不影响，CPU 一个一个运行。
  • fork 函数创建的进程和主进程平行运行，比如一个函数调用 fork 创建了进程后，进程不会随着函数结束而结束。

C 语言举例

运行后会出现两个值，一个零，一个非零。

wait

  • wait：等待。
  • 作用：使调用 wait 的父进程会等子进程运行完成后，再运行。
  • 没有子进程,会直接报错

C 语言举例

exit

  • exit：退出函数。

C 语言举例

exec 函数族

  • 函数命名规则：exec + l / v + p / e
  • 作用：用于命令进程执行操作。函数会替代原有进程,如果报错,则继续执行原进程
  • 传入的参数为：
    1. 执行文件
    2. 命令参数
    3. 环境变量
