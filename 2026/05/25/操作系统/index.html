空闲空间管理方法

1. 空闲表法

  • 定义：系统为每个空闲区域建立一张表，记录空闲块的起始地址和长度。
  • 数据结构：一张线性表，每个表项包含（起始地址，长度）。
  • 主要操作：
    • 分配：遍历空闲表，按首次适应、最佳适应、最差适应等算法查找合适空闲块，分配后更新表项。
    • 回收：将回收的空闲块插入空闲表，并尝试与相邻空闲块合并（若相邻）。
  • 特点：适用于连续分配方式，回收时合并开销较大。

2. 空闲链表法

  • 定义：将所有空闲块通过指针链接成一个链表，每个空闲块头部存放指向下一个空闲块的指针。
  • 数据结构：单链表或双向链表，链表结点包含空闲块信息（如大小）和指针。
  • 主要操作：
    • 分配：从链表头开始搜索，按算法选择空闲块，分配后删除结点或修改结点信息。
    • 回收：将回收块插入链表（通常按地址排序），并执行相邻合并。
  • 特点：实现简单，但链表遍历效率较低。

3. 位示图法

  • 定义：用二进制位（bit）表示每个存储块（如磁盘块）的使用状态：0 表示空闲，1 表示已分配。
  • 数据结构：一个位图（bitmap），通常为连续内存区域，每个 bit 对应一个物理块。
  • 主要操作：
    • 分配：扫描位图找到连续若干个 0 位，将其置为 1，并返回对应块号。
    • 回收：将对应块的 bit 置为 0。
  • 特点：空间开销小（每个块仅1 bit），分配和回收速度快，适合大容量存储管理。

4. 成组链接法（成组链接法，OCR中“戌组”应为“成组”）

  • 定义：将空闲块分组管理，每组包含若干块，组内用链表链接，组间通过专用块（超级块）中的指针链接。常用于 Unix 文件系统。
  • 数据结构：
    • 超级块：存放第一个空闲组的信息（组内空闲块数、块号列表）。
    • 空闲组：每组第一个块作为索引块，存放下一组空闲块数及块号列表，其余块为空闲块。
  • 主要操作：
    • 分配：从超级块中的当前组取一个空闲块；若当前组用完，则将下一组（通过索引块）的块号列表读入超级块。
    • 回收：将回收块放入当前组，若当前组已满（如 100 块），则新建一个组（将该块作为索引块，挂接下一组）。
  • 特点：兼顾节省空间与分配效率，适合大量空闲块的管理。

空闲空间表法

概述

空闲空间表法是一种用于管理磁盘存储空间的方法，通过维护一张空闲块表（或空闲区表）来记录所有未分配的空闲块信息。

主要操作

  1. 空闲块分配

    • 从空闲块表中查找合适的空闲块（如连续块），分配给文件使用。
    • 适用于存放连续文件时效率较高。

  2. 空闲块回收

    • 文件删除后，将其占用的块重新标记为空闲，并合并相邻空闲块（若适用），更新空闲块表。

优缺点

优点

  • 特别适于存放连续文件：因为表结构便于查找连续的空闲区域，适合文件连续存储。

缺点

  • 检索效率降低：当存储空间中出现大量的小空闲区时，空闲块表变得冗长，查找合适的空闲块需要遍历大量记录，导致效率下降。
  • 产生外部碎片：由于多次分配和回收，磁盘上会形成许多不连续的小空闲区，即外部碎片，造成磁盘空间浪费（原文中“溪费”应为“浪费”）。

适用场景

  • 适用于文件大小变化不大、且需要连续存储的场景（如早期的文件系统或特定存储需求）。

注：原文中“空 采 空间 表 法”应为“空闲空间表法”或“空闲块表法”。

请求分页存储管理与基本分页存储管理的主要区别

核心区别

  • 在程序执行过程中，当所访问的信息不在内存时，由操作系统负责将所需信息从外存调入内存，然后继续执行程序。
  • 若内存空间不够，由操作系统负责将内存中暂时用不到的信息换出到外存。

关键特点

  • 支持虚拟内存，允许程序在部分页面不在内存时仍可执行。
  • 页面的换入和换出由操作系统动态管理，需要借助磁盘I/O完成。

页面置换算法

作用

  • 决定当内存空间不足时，应该换出哪一页（即选择哪个页面被置换到外存）。

常见的四种页面置换算法

算法名称 缩写 基本思想
最佳置换算法 OPT 选择未来最长时间不会被访问的页面进行置换（实际无法实现，用于理论评估）
先进先出置换算法 FIFO 选择最早进入内存的页面进行置换（简单但可能产生Belady异常）
最近最久未使用置换算法 LRU 选择最近最长时间未被访问的页面进行置换（性能较好，但实现开销较大）
时钟置换算法 CLOCK 近似LRU，通过循环扫描页面并利用访问位决定是否置换（常用且实现简单）

补充说明

  • 页面的换入、换出都需要访问磁盘，因此选择好的页面置换算法有助于减少缺页率，提高系统性能。
  • 视频中提到的“好的页面置换算法”可帮助降低磁盘I/O次数，提升系统效率。

笔记总结

  • 请求分页与基本分页的主要区别在于：缺页时动态调页，内存不足时换出。
  • 页面置换算法是请求分页存储管理的核心机制之一，常见的包括OPT、FIFO、LRU、CLOCK。
  • 实际系统中通常采用LRU或CLOCK的近似实现，以平衡性能与开销。

最佳置换算法（OPT, Optimal）

定义

最佳置换算法（OPT）是一种理想化的页面置换算法。其核心思想是：每次选择淘汰的页面将是以后永不使用的，或者在最长（未来）时间内不再被访问的页面。这样可以保证最低的缺页率。

特点

  • 缺页时，如果当前内存块中还有空闲块，则直接调入新页面，不进行页面置换。
  • 仅当内存块已满且发生缺页时，才需要页面置换。
  • 该算法无法在实际系统中实现，因为需要预知未来页面访问序列，但常用于理论分析和性能对比。
