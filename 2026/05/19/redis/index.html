Redis 数据类型特点

Redis 支持多种数据结构，每种都有其独特的特性和适用场景。以下是主要数据类型的详细说明。

1. 字符串（String）

  • 定义：最简单的数据类型，存储普通字符串（二进制安全，可包含文本、数字、序列化对象等）。
  • 特点：
    • 一个键对应一个值。
    • 值最大可存储 512 MB。
    • 支持原子性操作（如自增、自减）。
  • 类比：类似于 Java 中的 String 或基本类型包装类（但更灵活，可直接进行数值操作）。

2. 哈希（Hash）

  • 定义：也叫散列，是一个键值对集合，字段（field）和值（value）都是字符串。
  • 特点：
    • 适合存储对象（如用户信息），每个 hash 可以包含多个字段。
    • 可以对单个字段进行增删改查，内存效率高。
    • 没有重复字段（字段名唯一）。
  • 类比：类似于 Java 中的 HashMap<String, String> 结构。

3. 列表（List）

  • 定义：按插入顺序排序的字符串列表，元素可重复。
  • 特点：
    • 支持在两端插入或弹出元素（左/右操作），实现队列或栈。
    • 基于链表实现，因此两端操作快，但索引访问慢（时间复杂度 O(N)）。
    • 元素允许重复。
  • 类比：类似于 Java 中的 LinkedList（但 Redis 列表是双向链表）。

4. 集合（Set）

  • 定义：无序的字符串集合，不允许重复元素。
  • 特点：
    • 支持集合运算（交集、并集、差集）。
    • 查找元素是否存在非常快（O(1)）。
    • 元素顺序不固定，插入顺序不保证。
  • 类比：类似于 Java 中的 HashSet。

5. 有序集合（Sorted Set / ZSet）

  • 定义：集合中的每个元素关联一个分数（score），根据分数升序排序，不允许重复元素。
  • 特点：
    • 既可以按分数范围查询，也可以按元素排名查询。
    • 底层使用跳跃表（skiplist）和哈希表实现，读写性能平衡。
    • 分数可以相同（此时按元素字典序排序）。
  • 类比：类似于 Java 中的 TreeSet 或 PriorityQueue（但支持分数更新和范围查询）。

Redis 字符串操作命令

概述

Redis 字符串类型是最基本的数据类型，常用命令如下：

1. SET key value

  • 功能：设置指定 key 的值。
  • 示例：SET name "Alice" 将键 name 的值设为 "Alice"。

2. GET key

  • 功能：获取指定 key 的值。
  • 示例：GET name 返回 "Alice"。

3. SETEX key seconds value

  • 功能：设置指定 key 的值，同时将 key 的过期时间设为 seconds 秒。
  • 说明：这是一个原子操作，等价于先执行 SET 再执行 EXPIRE。
  • 示例：SETEX code 60 "123456" 将键 code 的值设为 "123456"，并在60秒后自动删除。

4. SETNX key value

  • 功能：只有当 key 不存在 时，才设置 key 的值（NX 即 Not eXists）。
  • 返回值：设置成功返回 1，失败（key 已存在）返回 0。
  • 示例：SETNX lock "1" 如果 lock 不存在则创建，否则不做任何操作。

SETEX 设置值+过期时间 原子操作

Redis 有序集合操作命令

定义

  • 有序集合（Sorted Set） 是 Redis 中一种数据结构，元素类型为 字符串（string），且不允许重复成员。
  • 每个元素都关联一个 double 类型的分数（score），Redis 根据分数对成员进行排序（分数相同时按字典序）。

常用命令

1. ZADD

  • 语法：ZADD key score1 member1 [score2 member2 ...]
  • 功能：向有序集合中添加一个或多个成员。若成员已存在，则更新其分数。
  • 参数：
    • key：有序集合的键名
    • score：分数（double 类型）
    • member：成员（string 类型）

2. ZRANGE

  • 语法：ZRANGE key start stop [WITHSCORES]
  • 功能：按分数从小到大的顺序，返回指定索引区间内的成员。索引从 0 开始，支持负数索引（如 -1 表示最后一个元素）。
  • 可选参数：
    • WITHSCORES：同时返回成员的分数（返回值中分数紧跟在成员之后）
  • 示例：ZRANGE myzset 0 2 WITHSCORES 返回分数最小的前 3 个成员及其分数。

3. ZINCRBY

  • 语法：ZINCRBY key increment member
  • 功能：为有序集合中指定成员的分数增加 increment（可正可负）。若成员不存在，则等同于执行 ZADD key increment member。
  • 返回值：更新后的分数（double 类型）

4. ZREM

  • 语法：ZREM key member [member ...]
  • 功能：移除有序集合中的一个或多个成员。成员不存在时忽略。
  • 返回值：实际被移除的成员数量

注意：以上命令均要求 key 存在且为有序集合类型，否则可能引发类型错误。所有命令时间复杂度均为 O(log N)（N 为有序集合中的元素个数），但 ZRANGE 的复杂度为 O(log N + M)（M 为返回的元素个数）。
